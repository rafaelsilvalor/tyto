Picture primitives that return blocks (TYTO-625): `framedPicture` draws a file in a frame (border, bar, rounded inside corners as one even-odd outline, an optional shadow) and `barePicture` draws it alone, each sized from an area and its parameter schema (`FRAMED_PICTURE_PARAMETERS`, `BARE_PICTURE_PARAMETERS`); `frameOutlinePath` builds the frame's outline.
