Shape primitives that return blocks (TYTO-886): `shape` (rect, rounded, capsule, circle) in the caller's paint with an optional outline, `rule`, `cornerBracket`, `plus` and `arrowShape`, each with its parameter schema; and the path helpers `arrowPath`, `cornerBracketPath`, `roundedRectPath`, `circlePath` and `capsulePath` for glyph data a template keeps.
