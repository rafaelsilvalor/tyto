TYTO-256: the settings and keybindings tabs read as what they are. A misspelt key or an unknown command is underlined in the editor, as a brief's mistakes are; the editor heading says "Settings" or "Keybindings"; the template picker, the format tabs, the slide and the zoom are gone from those tabs, and the preview says the file applies when it is saved. Choosing a template while `settings.json` was in front used to write a YAML block into the JSON; it no longer edits the file.
