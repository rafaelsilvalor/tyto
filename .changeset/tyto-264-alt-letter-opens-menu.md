TYTO-264: on Windows and Linux, Alt and a menu's letter opens that menu from the title bar: Alt+F opens File, Alt+E Edit, Alt+V View, Alt+W Window and Alt+H Help, and in Portuguese Alt+A Arquivo, Alt+E Editar, Alt+X Exibir, Alt+J Janela and Alt+D Ajuda. Holding Alt underlines each name's letter. The five menu names now follow the window's language; before, only File did, and Edit, View, Window and Help stayed in English. A key the editor uses, such as Alt+L to select the line, still goes to the editor. A shortcut a person or a plugin put on Alt and a letter takes that letter from the menus. macOS is unchanged.
