TYTO-278: File ▸ Open Folder opens a workspace folder, and File ▸ Close Folder closes it. A brief inside it previews and exports with the template, asset and font folders its `.tyto/project.json` names, the export dialog points at its output folder, and the folder comes back after a relaunch. The project file's problems, such as a key an untrusted folder may not use, are listed in the Problems panel with their place in the file (ADR 0113).
