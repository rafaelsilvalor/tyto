TYTO-365: while a folder is open, the explorer's header has three buttons beside its close button. New File… and New Folder… open the same name field as the context menu, in the selected folder, the selected file's folder, or the top of the folder. Collapse All closes every open folder at every depth, and a selection inside one moves to the top-level folder that holds it.
