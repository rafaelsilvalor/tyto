A recipe opens as a notebook: under each cell, its table (20 rows, then how many more), when it ran and how old its data is, a fold toggle, **Run from here** and, on a cell that fetches, **Fetch again**. Two commands do the same from the keyboard, Run recipe from this cell and Run recipe, fetching again. `@tyto/editor` gains `remeasureCellOutput`, for an output whose height changed in place.
