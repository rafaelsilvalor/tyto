A `.recipe` file opens in a tab of its own: in the recipe colours, with the verbs offered at the start of a line, run on a pause in typing, on save and by Run recipe, with one line under each cell and its problems in Problems. A `run x` whose recipe holds a source no longer fetches while typing, and editing an included recipe on disk reruns the cell that includes it.
