What a `tyto` command run in the window reports appears in the Problems panel: one section per run, under the command it ran, below the brief's own rows, for the last five runs. Each row shows the file and line the command printed. A row in a file a tab opens is a button, and main opens that file by run and row, never by a path the window names. A `render --types png` run from the window rasters through the export's own rasterizer. The panel to run commands from is TYTO-496.
