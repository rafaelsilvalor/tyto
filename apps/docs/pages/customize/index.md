# Customize

Tyto keeps what you change in two files you can open from the window: `settings.json` for how the window looks and behaves, and `keybindings.json` for which keys run which commands. Both are plain text and both apply as soon as you save.

- [settings.json](./settings-json.md) — how the file works, and what happens to a value it cannot use.
- [Keyboard shortcuts](./keybindings-json.md) — give a command a key, take one away.
- [Themes](./themes.md) — the window's colours, and themes from plugins.
- [Fonts and zoom](./fonts-and-zoom.md) — text sizes, faces and the zoom of the whole window.
- [The status bar](./status-bar.md) — which items show, and their colours.
- [Plugins](./plugins.md) — see and manage what extends Tyto.

Every setting is listed in [Settings](../reference/settings.md), every default key in [Keyboard shortcuts](../reference/keyboard-shortcuts.md), and every theme in [Themes](../reference/themes.md). [Where Tyto keeps your things](../get-started/install.md#where-tyto-keeps-your-things) says where the files are on disk.
