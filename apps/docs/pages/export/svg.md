# SVG

::: info How this page was checked
Every step was followed on 2026-10-19 on a development build of Tyto 0.7.0 (commit `e3d32e9`) on Windows 11, once with the window in English and once in Brazilian Portuguese. Menus and labels below are the English window's.
:::

An **SVG** file is a drawing rather than a grid of pixels: it stays sharp at any size, and design programs can open it to move things around.

Tick **SVG** in the Export dialog to get one per artwork and size, named like the images: `grid-01.svg`, `story-01.svg`. It can be ticked together with any image type.

- **Scale** does not apply: an SVG has no pixel size to double. Its width and height are the format's.
- **Quality** does not apply either.
- The fonts are carried inside the file, so it looks the same on a computer that does not have them. That is why an SVG is larger than the PNG of the same artwork.

Some programs that only show images — many social networks among them — do not accept SVG. Export a PNG alongside it for those.
