# Get started

Tyto turns a short text file — a **brief** — into finished artwork: you write the words, a **template** decides where they go and how they look, and the app draws every size the template knows. These three pages take you from the download to your first exported image.

1. [Install](./install.md) — which file to download, where Tyto keeps your settings, how updates arrive and how to uninstall.
2. [Your first artwork](./first-artwork.md) — from an empty window to a PNG on disk, step by step.
3. [Tour of the window](./window-tour.md) — the parts of the window and the names this manual gives them.
