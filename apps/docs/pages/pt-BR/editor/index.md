# O editor

O editor é onde se escreve um brief: abas e grupos de editores no meio, painéis em volta e uma prévia que desenha o brief enquanto você digita. [Conheça a janela](../get-started/window-tour.md) dá nome a cada parte; as páginas daqui dizem como trabalhar com cada uma.

Tudo o que a janela faz é um comando, executado pela barra de comandos com **Ctrl+K** (**Cmd+K** no macOS). As teclas abaixo são as padrão no Windows e no Linux; [Comandos](../reference/commands.md) lista cada comando com a tecla em cada sistema, e [Personalizar](../customize/) explica como trocá-las.
