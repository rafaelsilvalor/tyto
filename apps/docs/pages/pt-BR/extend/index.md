# Estender

O Tyto aceita templates próprios e plugins. Os guias de como escrevê-los existem **só em inglês**:
são escritos para quem programa e são os mesmos documentos que o repositório do Tyto guarda ao
lado do código, atualizados no mesmo pull request que muda o comportamento que descrevem. Uma
tradução seria uma segunda cópia a manter em dia.

- [Writing templates](/extend/template-authoring) (em inglês)
- [Writing plugins](/extend/plugin-authoring) (em inglês)
- [Plugin API](/extend/plugin-api) (em inglês)
