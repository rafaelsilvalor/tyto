# Referência

Listas escritas por um programa a partir do próprio código do Tyto, então elas dizem o que a versão que você instalou faz. Um teste reprova a build quando uma delas deixa de bater com o código.

- [Configurações](./settings.md) — todas as chaves do `settings.json`, o que cada uma faz e o valor padrão.
- [Atalhos de teclado](./keyboard-shortcuts.md) — todas as teclas que o app liga, no Windows, no Linux e no macOS.
- [Comandos](./commands.md) — tudo o que a barra de comandos roda, com o id e a tecla padrão.
- [Linha de comando](./command-line.md) — todos os comandos e opções do `tyto`.
- [Temas](./themes.md) — os temas de cores que vêm com o app.
