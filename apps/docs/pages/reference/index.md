# Reference

Lists written by a program from Tyto's own code, so they say what the version you installed does. A test fails the build when one of them no longer matches the code.

- [Settings](./settings.md) — every key of `settings.json`, what it does and its default.
- [Keyboard shortcuts](./keyboard-shortcuts.md) — every key the app binds, on Windows, Linux and macOS.
- [Commands](./commands.md) — everything the command bar can run, with its id and default key.
- [Command line](./command-line.md) — every `tyto` command and option.
- [Themes](./themes.md) — the colour themes that come with the app.
