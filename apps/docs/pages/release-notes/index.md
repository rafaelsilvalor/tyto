# Release notes

What changed in each version of the desktop app, newest first. Each page is the text published
with that release, written in Brazilian Portuguese.

- [Tyto 0.24.5](./desktop-v0.24.5) — a delivery record comes beside its row, and column colours carry on past a break
- [Tyto 0.24.3](./desktop-v0.24.3) — a lone asterisk is just an asterisk, and a delivery record keeps the fields you declare
- [Tyto 0.24.1](./desktop-v0.24.1) — recent folders survive an update, and a recipe keeps a delivery folder per row
- [Tyto 0.23.2](./desktop-v0.23.2) — a brief writes a stacked fraction, needs no indent, and nests tags by the template
- [Tyto 0.23.1](./desktop-v0.23.1) — the command panel works with files, aliases and variables, and a comment no longer breaks a slide
- [Tyto 0.22.0](./desktop-v0.22.0) — a recipe reads in blocks, like a notebook, and the command line signs in
- [Tyto 0.20.0](./desktop-v0.20.0) — an agent panel that talks to Claude, and agents that write briefs
- [Tyto 0.17.0](./desktop-v0.17.0) — an AI agent works with the open window and proposes edits
- [Tyto 0.15.0](./desktop-v0.15.0) — a fetched plugin brings everything, not only its templates
- [Tyto 0.14.1](./desktop-v0.14.1) — the gallery, the command panel and a terminal inside the window
- [Tyto 0.12.0](./desktop-v0.12.0) — a folder per delivery, exported with one click
- [Tyto 0.10.0](./desktop-v0.10.0) — templates from their own repositories, through plugin files
- [Tyto 0.7.0](./desktop-v0.7.0) — the app updates itself
- [Tyto 0.6.0](./desktop-v0.6.0)
- [Tyto 0.3.0](./desktop-v0.3.0) — the first beta

The manual online always describes the newest version. If your app is older, some of what it
describes may not be in your version yet: Help ▸ Documentation opens this site, and the app
offers the update when one is out.
