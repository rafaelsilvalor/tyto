# Explorations

A design session written down before it is settled.

**Nothing in this folder is binding.** `docs/adr/` holds closed decisions; this holds the
thinking that may become one. A note here records a model, the reasoning behind it and the
alternatives that were rejected, so that the next person does not re-derive the argument —
but it grants no permission to change code.

A note earns its place when the thinking cost real time and the answer is not yet a
decision. It leaves this folder in one of two ways:

- **It becomes an ADR**, and the note stays as the record of how that ADR was reached.
- **It becomes a "no"**, written into the note itself, with the reason.

Each note names the card that hosts it and carries the date it was written. A note whose
audit section cites line numbers is a snapshot: the code moves and the citations rot, which
is why the audit says what it measured and when.
